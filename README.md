# Osadnik

Jednoosobowa przeglądarkowa gra strategiczna inspirowana klasycznymi grami o rozwoju wioski.

## v0.1
- produkcja drewna, gliny i żelaza w czasie rzeczywistym
- 7 budynków i rozbudowa poziomów
- magazyn i limity surowców
- koszary oraz pikinierzy i miecznicy
- mapa 7×7 z wioską gracza, opuszczonymi osadami i botem
- raporty
- automatyczny i ręczny zapis w localStorage
- responsywny interfejs na komputer i telefon

## Uruchomienie
Otwórz `index.html` lokalnie albo opublikuj repozytorium przez GitHub Pages.

Kolejny etap: v0.2 — właściwy system ataków, czas przemarszu, bitwy, przejmowanie wiosek i aktywne AI botów.
